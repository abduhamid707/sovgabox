# Sovg‘aBox 🎁

Premium gift shopping experience built with React, Vite and TypeScript.

> **Demo frontend:** mahsulotlar va narxlar mock data; buyurtmalar faqat shu brauzerda saqlanadi. Hozircha haqiqiy to‘lov, yuborish, yetkazish yoki operatorga xabar yuborish ishlamaydi.

## Local run

```bash
git clone https://github.com/abduhamid707/sovgabox.git
cd sovgabox
npm install
npm run dev
```

Visit the local URL shown by Vite (usually http://localhost:5173).

## Scripts

- `npm run dev` — development server
- `npm run build` — typecheck and production build
- `npm run preview` — production build preview

## Stack

React 19, React Router 7, Vite, TypeScript, Tailwind CSS 4, Zustand, Motion and Lucide.

## Functionality

Homepage, ready-made gift boxes, product catalog, live Gift Builder with virtual box preview, favorites, cart, checkout, demo order history and mobile navigation. Packaging is confirmed later with the customer, not selected by dimensions. Mock data layer is isolated to ease future API integration.
